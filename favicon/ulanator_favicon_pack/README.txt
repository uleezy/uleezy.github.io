Ulanator favicon pack

Create a folder in your website called:
favicon

Put these files inside:
favicon.ico
favicon-32.png
favicon-180.png
favicon-192.png
favicon-512.png

Add this inside the <head> of index.html:

<link rel="icon" href="favicon/favicon.ico" sizes="any">
<link rel="icon" type="image/png" href="favicon/favicon-32.png">
<link rel="apple-touch-icon" href="favicon/favicon-180.png">
